Privacy Policy

nodeving · Last updated: November 12, 2026

nodeving is a private research tool. One developer runs it on their own computer to see which AI topics people are talking about on Threads, so that they can plan their own educational content about AI. It is not offered to the public. The only account that signs in to it is the developer's own Threads account.

Data we process

Threads account connection. When the developer connects their Threads account through Threads Login, the app receives an access token, the account's user ID, and its username. It keeps only the token and the username. The app never sees or stores the account password.

Keyword search results. When a keyword is searched through the Threads API, the app receives public posts that match it. For each post it receives the post ID, text, media type, link, time of posting, and the author's username. It does not receive private posts, messages, follower lists, or any other non-public information.

How we use it

  • The access token is used only to call the Threads API for the connected account.
  • Search results are shown to the developer and used to find which AI topics and search terms are being discussed.
  • To find those topics, the text of the returned posts may be analyzed by an AI language model service (Claude, by Anthropic). The service processes the text only to carry out this analysis for us.
  • We do not sell this data, use it for advertising, build profiles of individuals, contact the authors of posts, or republish posts.

Where it is kept and for how long

  • All data stays on the developer's own computer. The app has no external server and no cloud storage.
  • The access token is kept in a local file that only the developer's user account can read. It is kept until it expires, is revoked, or is deleted.
  • Search results are kept only as long as they are needed for content planning. They are deleted when they are no longer needed or when deletion is requested.

Sharing

We do not share this data with anyone, except the AI analysis service described above and where the law requires it.

Requests from public authorities

If a public authority asks us for data covered by this policy, we handle the request as follows:

  • We review whether the request is lawful before we respond.
  • We challenge the request if we find that it is not lawful.
  • We disclose only the minimum data that a lawful request requires.
  • We keep a record of each request, our response, and the reasons for it.

Deleting your data

Anyone can ask us to delete data that relates to them. This includes authors of public Threads posts that appeared in a search. Send a request to nodeving@gmail.com, or follow the steps on our Data Deletion Instructions page: https://nodeving.github.io/nodeving-policy/data-deletion.html. We delete the data promptly and confirm by email.

Changes

If the way we handle data changes, we will update this page and the date above.

개인정보처리방침

nodeving · 마지막으로 고친 날: 2026년 11월 12일

nodeving은 개인이 쓰는 조사 도구입니다. 개발자 한 사람이 자기 컴퓨터에서 돌립니다. 쓰레드에서 사람들이 어떤 AI 주제를 이야기하는지 살펴서 자신의 AI 교육 콘텐츠를 기획하는 데 씁니다. 일반에 공개하는 서비스가 아닙니다. 로그인하는 계정은 개발자 본인의 쓰레드 계정 하나뿐입니다.

처리하는 정보

쓰레드 계정 연결. 개발자가 쓰레드 로그인으로 자기 계정을 연결하면 앱은 액세스 토큰, 계정의 사용자 ID, 사용자 이름을 받습니다. 그 가운데 토큰과 사용자 이름만 둡니다. 계정 비밀번호는 보지도 저장하지도 않습니다.

키워드 검색 결과. 쓰레드 API로 키워드를 검색하면 앱은 그 키워드에 맞는 공개 게시물을 받습니다. 게시물마다 받는 것은 게시물 ID, 본문, 미디어 종류, 링크, 올린 시각, 작성자의 사용자 이름입니다. 비공개 게시물, 메시지, 팔로워 목록처럼 공개되지 않은 정보는 받지 않습니다.

쓰는 곳

  • 액세스 토큰은 연결한 계정으로 쓰레드 API를 부르는 데만 씁니다.
  • 검색 결과는 개발자에게 보여 주고, 어떤 AI 주제와 검색어가 이야기되고 있는지 찾는 데 씁니다.
  • 그 주제를 찾기 위해 받은 게시물의 본문을 AI 언어 모델 서비스(Anthropic의 Claude)로 분석할 수 있습니다. 이 서비스는 우리를 위해 이 분석을 하는 데만 본문을 처리합니다.
  • 이 정보를 팔지 않습니다. 광고에 쓰지 않습니다. 개인의 프로필을 만들지 않습니다. 게시물 작성자에게 연락하지 않습니다. 게시물을 다시 올리지 않습니다.

두는 곳과 기간

  • 모든 정보는 개발자 본인의 컴퓨터에만 둡니다. 앱에는 외부 서버도 클라우드 저장소도 없습니다.
  • 액세스 토큰은 개발자의 사용자 계정만 읽을 수 있는 파일에 둡니다. 만료되거나, 취소되거나, 지울 때까지 둡니다.
  • 검색 결과는 콘텐츠 기획에 필요한 동안만 둡니다. 더 필요하지 않거나 삭제 요청을 받으면 지웁니다.
